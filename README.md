# ProtectedDebugStick

A Minecraft server plugin that adds a legit, permission-gated debug stick for survival servers.

🔗 **Live:** [machiganmc.github.io/ProtectedDebugStick](https://machiganmc.github.io/ProtectedDebugStick/)   ·   ☕ **Support:** [Buy Me a Coffee](https://buymeacoffee.com/hackatoa)

## Overview

Brings the creative-mode debug stick to survival in a controlled way — permission-gated and region/protection-aware so it can be handed out safely.

## Features

- Debug-stick block-state editing on survival servers
- Permission-gated usage
- Respects protected regions

## Tech Stack

Java · Bukkit / Paper plugin

## Build

```bash
./gradlew build   # or: mvn package
```

## Install

Drop the built jar into your server's `plugins/` folder and restart.
